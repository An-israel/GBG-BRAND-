# 30-minute staff training script

Record the session (screen recording on the shop laptop). Have a test product and a test order ready.

| Time | Topic | Say / show | Staff try it |
|---|---|---|---|
| 0–3 | Why we're careful | "Customers trust us with their card. Honest condition, honest prices, stock that's really there." Show a product page. | – |
| 3–8 | **Creating a product** | Products → Add product. Title formula (colour + material + type + detail). Description from the item. Price, cost, SKU, weight. Untick *continue selling*. Metafields: Condition (required), notes, dimensions, tested. Tags: category + `new-arrival`. Save as **Draft**. | Create the "Training mug" draft. |
| 8–12 | **Uploading photos** | Main photo on white first, then angles, label, every fault. Drag to reorder. Alt text: "Navy mug – side view". (Bulk: `photos/<SKU>/` + `npm run images`.) | Add 3 photos. |
| 12–15 | **Variants** | Only for identical items in sizes/colours: Add options → Size → 5, 6, 7 – each with own SKU and stock. One-offs are separate products. | Add sizes to a test shoe. |
| 15–18 | **Stock adjustments** | Product → Inventory at Unit M10 → adjust. Sold in the shop without POS? Adjust **straight away**. With POS it's automatic. | Reduce the mug from 2 to 1 – see "Only 1 left". |
| 18–21 | **Condition labels** | Walk through the six labels and their meanings (FAQ page). "Unchecked never means no refunds." When in doubt, choose the lower condition and describe it. | Pick labels for 3 real items. |
| 21–27 | **Orders and pickups** | Delivery order: pick, pack, fulfil, tracking. Pickup order: set aside, *Mark as ready for pickup*, check order number, *Mark as picked up*. | Process the test pickup order. |
| 27–30 | **Refunds** | Managers only. Orders → Refund → items → reason. 14-day cancellation online; faulty goods always have rights. Questions. | – |

After training: hand over the printed STAFF_SOP and PRODUCT_CSV_GUIDE.
